Fixes a bug where the website/docs chat widget would complete a run and show nothing back - Mastra's streaming chunks and CopilotKit's runtime expected different shapes, so every answer was silently empty. Widget messages, config errors, and mobile layout got several smaller fixes alongside it.

Settings → AI Model's Model ID field now fetches each provider's current model list live instead of relying on a hardcoded list that went stale between releases, and adds xAI (Grok) as a supported provider.

@answerloops/agent-sdk bumped to 0.6.1 and the Agent API's OpenAPI spec to 1.1.1, both previously held steady since the /v1/ path rename.
