@answerloops/agent-sdk now ships a CLI: npx @answerloops/agent-sdk setup bootstraps a self-hosted instance without Claude Code, and npx @answerloops/agent-sdk skills installs the Claude Code agent skills. The answerloops-setup skill now delegates its mechanical steps to this CLI instead of duplicating the logic in bash. Dashboard and README updated to match.
