The widget grows up: Pro workspaces can brand it and give it starter questions, every reply is formatted and can suggest follow-ups, and owners can limit it to their own knowledge base.

### ⚠️ Breaking changes & upgrade steps
- **`AUTH_SECRET` must be a random value of at least 32 characters in production**, or the server won't start. If yours is short or a placeholder, generate a new one with `openssl rand -hex 32`; changing it signs everyone out once. ([#590](https://github.com/answerLoops/answerLoops/issues/590))
- **Six database migrations (`0077`–`0082`) run automatically on startup.** Back up first as usual if you self-host.

### New
- **Widget appearance (Pro and above)** — set the chat title, welcome message and brand color under Settings → Widget. Text color on top of the brand color is picked automatically so it stays readable, and the launcher and chat panel follow your color. [Docs](https://answerloops.com/docs/product/chat-widget) by [@NathanTarbert](https://github.com/NathanTarbert) ([#643](https://github.com/answerLoops/answerLoops/issues/643), [#652](https://github.com/answerLoops/answerLoops/issues/652))
- **Welcome card and starter questions** — the widget's first screen is now a welcome card for every workspace. Pro and above can add up to four tappable starter questions. by [@NathanTarbert](https://github.com/NathanTarbert) ([#647](https://github.com/answerLoops/answerLoops/issues/647))
- **Follow-up suggestions** — after an answer the widget can offer two or three short next questions as buttons, used sparingly and never after a refusal, a contact answer or an "I don't know". by [@NathanTarbert](https://github.com/NathanTarbert) ([#673](https://github.com/answerLoops/answerLoops/issues/673))
- **Answer scope** — under Settings → Widget, choose "Only from my knowledge base" so the widget answers only from published articles, says plainly when they don't cover a question, and politely declines off-topic requests. by [@NathanTarbert](https://github.com/NathanTarbert) ([#626](https://github.com/answerLoops/answerLoops/issues/626))
- **Lead emails** — when a visitor leaves an email in the chat, workspace owners and admins get a short email with the address, the unanswered question and a link to the Leads page. At most one lead email goes out every 10 minutes per workspace. by [@NathanTarbert](https://github.com/NathanTarbert) ([#669](https://github.com/answerLoops/answerLoops/issues/669))
- **Stale-resolution flags** — when a connected repository's docs change, saved resolutions that relate to the changed content are flagged on the Knowledge Base page so you can re-check them. by [@NathanTarbert](https://github.com/NathanTarbert) ([#566](https://github.com/answerLoops/answerLoops/issues/566))
- **Source support** — answers are now checked against the knowledge-base articles they were written from, after the reply goes out, and the result is stored. A `pnpm support:shadow` command samples stored findings and builds a go/no-go report. by [@NathanTarbert](https://github.com/NathanTarbert) ([#580](https://github.com/answerLoops/answerLoops/issues/580), [#581](https://github.com/answerLoops/answerLoops/issues/581))
- **Mark all as seen** on the dashboard Activity panel, with a confirmation showing how many tickets it affects. by [@ravirraj](https://github.com/ravirraj) ([#653](https://github.com/answerLoops/answerLoops/issues/653))
- **Docs dark mode** — the documentation site has a light/dark toggle again. by [@rudraparmar76](https://github.com/rudraparmar76) ([#569](https://github.com/answerLoops/answerLoops/issues/569))
- **Publish confirmation for Notion imports** — Publish to widget now asks first, showing how many chunks will go live. by [@NathanTarbert](https://github.com/NathanTarbert) ([#617](https://github.com/answerLoops/answerLoops/issues/617))

### Improved
- The answer reviewer now sees the same knowledge-base sources as the draft and checks specific claims against them. A claim the sources don't back lowers confidence, so unsupported answers are less likely to auto-reply. ([#573](https://github.com/answerLoops/answerLoops/issues/573))
- On bug reports and feature requests, a workaround is only posted when a check confirms it fits that specific report. ([#578](https://github.com/answerLoops/answerLoops/issues/578))
- The dashboard Activity panel starts collapsed. by [@ravirraj](https://github.com/ravirraj) ([#637](https://github.com/answerLoops/answerLoops/issues/637))
- Docs search results read as plain sentences instead of showing page-component or table markup. ([#622](https://github.com/answerLoops/answerLoops/issues/622))
- GitHub ticket messages render Markdown properly in the ticket view. by [@virginiamwega2-svg](https://github.com/virginiamwega2-svg) ([#628](https://github.com/answerLoops/answerLoops/issues/628))
- Failures in the support agent's repository tools are logged on the server with details, and the model gets a short generic message. ([#577](https://github.com/answerLoops/answerLoops/issues/577))

### Fixed
- The widget no longer shows "session timed out" to someone who just read the page for a while before opening the chat, and it keeps the conversation across a page refresh. When an open chat does go stale, the next message recovers instead of showing a bare "Forbidden". ([#642](https://github.com/answerLoops/answerLoops/issues/642), [#651](https://github.com/answerLoops/answerLoops/issues/651))
- Widget replies showed raw formatting markers; bold, italic, inline code, short lists and links now render. ([#642](https://github.com/answerLoops/answerLoops/issues/642))
- The Discourse "Register webhook" button now works against a real Discourse and explains when your account lacks permission. [Docs](https://answerloops.com/docs/integrations/discourse) ([#602](https://github.com/answerLoops/answerLoops/issues/602))
- A long AI explanation could make a ticket's answer fail; it is now trimmed, and a triage failure no longer stops the AI answer or the team notification. ([#603](https://github.com/answerLoops/answerLoops/issues/603))
- Product-feedback alert emails now report send failures, and the sender falls back to a real address when `RESEND_FROM` is unset. ([#608](https://github.com/answerLoops/answerLoops/issues/608))
- The feedback board's sort button could disagree with the list on screen after a failed request. ([#567](https://github.com/answerLoops/answerLoops/issues/567))
- The brand-color sample in Widget settings looked like a button people clicked; it is now clearly a preview. ([#652](https://github.com/answerLoops/answerLoops/issues/652))
