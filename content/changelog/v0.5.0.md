Open-source AI support that lives in your community. AnswerLoops takes the first pass at repeat questions in the channels where people actually ask — and only replies when a second pass says the answer is good enough. Everything else goes to a human with a draft ready to edit.

### What's in this release

- **Confidence-gated answering** — every draft is scored against the evidence it used; you set the threshold that decides post vs. escalate. Bug reports and feature requests always stay human-led.
- **One pipeline for every channel** — Discord, Slack, Discourse and Circle forums, GitHub Issues/Discussions, Telegram, email, an embeddable web widget, and Google Chat all land in the same org-scoped ticket model.
- **Grounded in your content** — retrieval across crawled docs, uploaded files, published KB articles, resolved tickets, a synced GitHub repo, and a Notion workspace.
- **Bring your own model** — OpenAI, Anthropic, Google Gemini, Groq, Mistral, Ollama, or any OpenAI-compatible endpoint, on your key.
- **Agent access** — MCP server (JSON-RPC) and a REST API with an OpenAPI schema expose the same knowledge and workflows.
- **Self-hostable** — AGPL-3.0. `docker compose up` runs the app, the listener, and Postgres on your own infrastructure; tenant data is scoped by org and integration credentials are encrypted at rest.
- **Analytics** — deflection rate, hours saved, per-category accuracy, SLA attainment, and a knowledge-gaps view of what the system still can't answer.
