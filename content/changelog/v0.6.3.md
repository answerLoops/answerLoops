Faster, bounded ticket lists on the dashboard, a more useful Open card, and a round of dependency updates. The container image, the app and `@answerloops/agent-sdk` all report 0.6.3.

### Upgrade notes
- **Node 22 or newer is required.** The `engines` field moved from `>=20.9` to `>=22`. The Docker image, CI and `.nvmrc` already ran Node 22, so container users need to do nothing; if you run from source on Node 20, upgrade first. ([#250](https://github.com/answerLoops/answerLoops/issues/250))
- **A new migration (`0046`) runs automatically on start.** It adds two tables used by the in-app feedback widget. The widget is off by default and has no effect on self-hosted deployments. ([#323](https://github.com/answerLoops/answerLoops/issues/323))
- **Extra database tables are created on first start.** The AI memory library was updated and now creates a handful of additional tables the app doesn't use. Existing conversations and their history are untouched. The database user needs permission to create tables, which it already needs today. ([#320](https://github.com/answerLoops/answerLoops/issues/320))

### New
- **Related articles on blog posts.** Posts now carry tags, and each post page ends with up to three related articles ranked by shared tags, falling back to the same category. ([#299](https://github.com/answerLoops/answerLoops/issues/299))
- **In-app feedback widget on the dashboard**, available to the hosted deployment. ([#323](https://github.com/answerLoops/answerLoops/issues/323), [#324](https://github.com/answerLoops/answerLoops/issues/324))

### Improved
- **Dashboard ticket lists are paginated.** The tickets page, its API route and the dashboard's recent-tickets panel used to load an organization's whole ticket history. They now load 50 at a time with a "Load more" button, using the same cursor pagination as the Agent API. Large workspaces will see lighter pages and faster loads. ([#295](https://github.com/answerLoops/answerLoops/issues/295))
- **The Open card on the dashboard is a link.** Select it, or tab to it and press Enter, to jump to `/tickets?status=open`. [Docs](https://answerloops.com/docs/product/dashboard) by [@cracthatrock](https://github.com/cracthatrock) ([#298](https://github.com/answerLoops/answerLoops/issues/298))

### Fixed
- The "View all" link on the Open tickets panel opened an unfiltered list that could include resolved tickets. It now opens the list filtered to Open. by [@Soch126](https://github.com/Soch126) ([#306](https://github.com/answerLoops/answerLoops/issues/306))

### Agent SDK
- No API changes. Published as `agent-sdk-v0.6.3` so the npm package version matches the release. ([#325](https://github.com/answerLoops/answerLoops/issues/325))

### Dependency updates
- Updated the widget chat runtime, the AI memory and database libraries, the error-reporting SDK (v11, with request bodies and cookies still excluded from error events) and a batch of patch and minor packages. Removed an unused dependency. ([#313](https://github.com/answerLoops/answerLoops/issues/313), [#316](https://github.com/answerLoops/answerLoops/issues/316), [#315](https://github.com/answerLoops/answerLoops/issues/315), [#319](https://github.com/answerLoops/answerLoops/issues/319), [#320](https://github.com/answerLoops/answerLoops/issues/320))
