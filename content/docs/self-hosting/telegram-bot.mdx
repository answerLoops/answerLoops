Connecting Telegram works the same way on a self-hosted deployment as on managed cloud — there's no separate self-hosting flow. Create a bot with [@BotFather](https://t.me/BotFather), copy the token it gives you, and paste it into **Integrations → Telegram**. See the [full Telegram setup guide](/docs/integrations/telegram) for the step-by-step walkthrough, chat ID lookup, and troubleshooting.

## Self-hosting-specific env var

One optional environment variable matters only for self-hosted deployments — everything else is configured per-organization through the Settings UI:

```dotenv
TELEGRAM_BOT_TOKEN=123456789:AAHdqTcv...  # optional fallback token, skips per-org setup for a single-tenant deployment
TELEGRAM_WEBHOOK_BASE_URL=https://your-tunnel.example.com  # optional, overrides AUTH_URL for the webhook only — see the integration guide's troubleshooting for when you need this
```

For everything else — creating the bot, finding a chat ID, registering the webhook, and diagnosing a bot that connects but never replies — see [Telegram](/docs/integrations/telegram).
