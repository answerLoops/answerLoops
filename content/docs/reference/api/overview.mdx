This is the index of the Agent API's endpoints. Pick an operation below to see every parameter and response field, generated directly from the live OpenAPI spec at [`/api/v1/agent/openapi.json`](/api/v1/agent/openapi.json).

For setup, auth, error shapes, and rate limits, see the [Agent API guide](/docs/integrations/agent-api).

## Make your first call

Create an API key in **Settings → API Keys**, then search your knowledge base. Replace the base URL with your own domain if you self-host.

<Tabs items={['curl', 'TypeScript']}>
  <Tab value="curl">
```bash
curl -H "Authorization: Bearer <your-api-key>" \
  "https://answerloops.com/api/v1/agent/kb/search?query=how+do+I+reset+my+api+key&limit=5"
```
  </Tab>
  <Tab value="TypeScript">
```ts
import { AgentClient } from "@answerloops/agent-sdk";

const client = new AgentClient({ apiKey: process.env.ANSWERLOOPS_API_KEY! });

const { results } = await client.searchKb({ query: "how do I reset my api key" });
```
  </Tab>
</Tabs>

Each result has a `question`, an `answer` and a `score`.
